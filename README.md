# ⚡ Python GUI To-Do List App

Bu proje **Vibe Coding** konseptiyle, **OpenCode-AI** ve **OpenRouter** üzerinden çağrılan açık kaynaklı LLM modelleri rehberliğinde sıfırdan inşa edilmiştir.

### 🛠️ Öne Çıkan Özellikler:
- 📁 **Kategori & Proje Yönetimi:** Görevleri gruplama ve ilişkili silme (Cascade Delete)
- ⏰ **Zaman Planlaması:** Görevlere özel opsiyonel saat aralıkları
- 🌓 **Tema Desteği:** Dark ve Light mod arası geçiş
- 💾 **Kalıcı Veri:** SQLite veritabanı entegrasyonu
